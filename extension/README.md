# Kult Player Bridge

Расширение связывает видеоплеер с комнатой Kult и работает только на `http://194.226.165.6:8787/`.

## Установка

1. Откройте `chrome://extensions` (в Яндекс Браузере — `browser://extensions`).
2. Включите режим разработчика.
3. Нажмите **Загрузить распакованное расширение** и выберите папку `extension`.
4. После обновления файлов нажмите **Обновить** на карточке расширения в каждом браузере.

## Использование

Откройте комнату Kult и дождитесь появления плеера. Поверх него будет показан экран активации. Один раз нажмите **Активировать плеер**: расширение кратко запускает видео, затем останавливает его и возвращает позицию на `00:00`.

Этот единственный клик нужен из-за браузерного запрета на автоматическое воспроизведение со звуком. Выдавать разрешения через popup больше не требуется. Popup теперь только показывает состояние подключения.

После активации обычные кнопки Play, Pause и перемотки внутри плеера синхронизируются с участниками комнаты. Расширение также передаёт текущую позицию, состояние буферизации и доступные показатели соединения для списка участников.

Расширение обрабатывает только iframe `bulkikim.lol` и `theatre.stravers.live`. Рекламные и служебные iframe игнорируются.

## Значок расширения

- `ON` — плеер подключён;
- `…` — плеер загружается;
- `!` — требуется однократная активация пользователем;
- пустой значок — открыта не страница Kult.
