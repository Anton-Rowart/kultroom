# Kult Watch Party

Локальный MVP совместного просмотра: сайт-комната, WebSocket-сервер и Chrome-расширение для управления плеером во вложенном iframe.

## Запуск

```bash
npm install
npm start
```

Откройте `http://127.0.0.1:8787`. На стартовом экране введите имя и ссылку на фильм, затем нажмите **Создать комнату**. Сайт создаст шестизначный код и добавит его в URL.

Можно продолжать открывать `index.html` через Live Server на `http://127.0.0.1:5500`: клиент автоматически подключится к WebSocket-серверу на порту `8787`. Сам `npm start` при этом всё равно должен быть запущен.

## Расширение

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Загрузите распакованное расширение из папки `extension` или обновите уже загруженное.
4. Для встроенных `bulkikim.lol` и `theatre.stravers.live` доступ уже объявлен в расширении. Для нового видеосайта откройте popup и один раз разрешите найденный домен.
5. Значок показывает `ON` на вкладке Kult, `!` при необходимом разрешении и неактивен на остальных сайтах.

После этого расширение автоматически отслеживает штатные Play, Pause и перемотку плеера. События отправляются в комнату, а команды других участников применяются в их iframe.

## Проверка двумя браузерами

1. В первом браузере создайте комнату и нажмите **Поделиться комнатой**.
2. Откройте скопированную ссылку во втором браузере и введите имя участника.
3. В обоих браузерах установите/включите расширение и предоставьте доступ к доменам.
4. Список участников должен показать двух пользователей.
5. При необходимости один раз нажмите штатный Play в каждом браузере, чтобы браузер разрешил воспроизведение со звуком.
6. После этого Play, Pause и перемотка в одном браузере передаются второму.

Для теста на одном компьютере достаточно `127.0.0.1`. Для подключения с другого устройства сервер нужно открыть по LAN-адресу компьютера или развернуть на публичном HTTPS-домене.

## Тесты

```bash
npm test
```

Интеграционный тест запускает сервер, подключает владельца и гостя, проверяет роли, запрет гостю менять ссылку, смену ссылки владельцем, Play и Pause.
