# Kult Watch Party

Сервис совместного просмотра: сайт-комната, WebSocket-сервер и расширение для синхронизации плеера во вложенном iframe.

## Запуск

```bash
npm install
npm start
```

В локальной среде откройте `http://127.0.0.1:8787`. На сервере рабочий адрес — `http://194.226.165.6:8787/`. Введите имя и ссылку на фильм, затем нажмите **Создать комнату**. Сайт создаст шестизначный код и добавит его в URL.

Можно продолжать открывать `index.html` через Live Server на `http://127.0.0.1:5500`: клиент автоматически подключится к WebSocket-серверу на порту `8787`. Сам `npm start` при этом всё равно должен быть запущен.

## Расширение

1. Откройте `chrome://extensions`.
2. Включите режим разработчика.
3. Загрузите распакованное расширение из папки `extension` или обновите уже загруженное.
4. Откройте `http://194.226.165.6:8787/`. На других сайтах расширение не работает.
5. Когда загрузится плеер, один раз нажмите **Активировать плеер** на затемнённом экране поверх видео.

Отдельно разрешать домены через popup не требуется. Один реальный клик по экрану активации необходим из-за политики автозапуска браузеров. Во время активации расширение кратко запускает видео, затем ставит его на паузу и возвращает на `00:00`.

После этого расширение отслеживает штатные Play, Pause и перемотку. События отправляются в комнату, а команды других участников применяются в их iframe. В списке участников отображаются позиция, состояние воспроизведения, буферизация, задержка до сервера и приблизительное качество соединения.

## Проверка двумя браузерами

1. В первом браузере создайте комнату и нажмите **Поделиться комнатой**.
2. Откройте скопированную ссылку во втором браузере и введите имя участника.
3. В обоих браузерах установите или обновите расширение.
4. Список участников должен показать двух пользователей.
5. Один раз нажмите **Активировать плеер** в каждом браузере.
6. После этого Play, Pause и перемотка в одном браузере передаются второму.

Для теста на одном компьютере достаточно `127.0.0.1`. Для подключения с другого устройства сервер нужно открыть по LAN-адресу компьютера или развернуть на публичном HTTPS-домене.

## Тесты

```bash
npm test
```

Интеграционный тест запускает сервер, подключает владельца и гостя, проверяет роли, запрет гостю менять ссылку, смену ссылки владельцем, Play/Pause, телеметрию и Ping/Pong.
